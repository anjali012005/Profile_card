## 🎴 Profile Card Practice Project

A simple and visually appealing Profile Card UI built using HTML, CSS, and basic frontend concepts.
This project was created to practice designing clean, responsive components and improving UI/UX skills.

<img width="1910" height="965" alt="image" src="https://github.com/user-attachments/assets/cbfdffb5-9073-4be9-b1fc-c21f4586ae8a" />

📌 Overview

This profile card displays:

👤 Profile image

📝 Name & short bio

🌐 Social links (LinkedIn & GitHub)

✨ Modern and minimal UI

📱 Fully responsive design

It is a great beginner-friendly practice project for improving styling, alignment, and layout skills.

🛠️ Tech Used

HTML5

CSS3
